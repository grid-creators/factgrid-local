FactGrid Chat lädt …

Anmelden

Der FactGrid-Chat ist nur für angemeldete Personen zugänglich. Jede Anmeldung hat ein eigenes Profil mit eigenem API-Schlüssel.

API-Schlüssel

Der Schlüssel wird in deinem Profil gespeichert und nur für deine Fragen benutzt. Er geht an den lokalen Chat-Server und von dort an den Anbieter – nie zurück an den Browser.

Permanenter Link

Wer diesen Link hat, kann das Gespräch lesen – ohne Anmeldung, aber nur lesend. Der Link bleibt gültig, solange das Gespräch nicht gelöscht wird. Wer angemeldet ist, kann das Gespräch von dort aus als eigenes weiterführen; das bekommt dann einen eigenen Link.
Von dieser Datei liegt nur der Anfang auf dem Server – was danach kommt, kennt der Chat nicht.
Geteiltes Gespräch – nur zum Lesen.
